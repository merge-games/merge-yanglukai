# 合成杨璐恺

同学头像合成小游戏（玩法来自“合成大西瓜”）。

## 玩法

- 左右拖动顶部头像瞄准，松手落下（手机可倾斜机身微调水平方向；桌面端 `←` `→` 瞄准，`空格` / `↓` 落下，`Esc` 关闭弹窗）。
- 两个**相同头像**碰到一起，会合成**更大一级**的头像并获得分数。
- 头像堆过顶部虚线并停留一段时间，本局结束。
- 点击右上角 **图鉴** 可查看合成链（小 → 大）：**在游戏里出现过（投放下来或合成出来）的等级才会显示头像，没出现过的显示“不详”**，收集进度保存在本机。
- 底部可选 **低难度 / 高难度 / 超低难度**，只影响“随机投放”能拿到哪些等级（图鉴、最高分不受影响）。**每次进游戏都从低难度开始**（难度不做记忆），掉落范围也**每局重新计算**：
  - **低难度**：掉落范围跟着**本局合成过的最高级**走，上限 = 该等级 − 5；开局 5 种，本局内合成到第 10 级放宽到 6 种、第 11 级放宽到 7 种；放宽时会飘字提示“掉落范围扩大！”；
  - **高难度**：只投放最小的 5 级，并且**得分 ×2**；
  - **超低难度**（点选后先弹确认框）：**固定投放到第 10 级**（共 11 种），而且**等级越高越容易被投放**（权重 =（等级+1）²）——掉两个第 10 级一碰就是最大级。
- **最高分按难度分开记录**：顶栏显示「最高·低 / 最高·高 / 最高·超」，切换难度即切换纪录。
- **复活币**：满 3000 分起、每多 1000 分送 1 枚；本局结束时若还有复活币，可「用复活币复活」，复活会清掉越过警戒线的头像并接着本局继续。
- **合成出最大级**会触发全屏庆祝特效（放大铺满 + 旋转光芒 + 金粉 + 标题），并**清空场上其他所有头像**，动画结束后继续玩。

## 素材说明

```
合成杨璐恺/
├─ index.html            游戏本体（单文件，无依赖）
├─ README.md
├─ picture/              原始照片 001.jpg ~ 012.jpg（按等级顺序，体积大，不进仓库）
├─ assets/               裁切后的头像（512×512，共约 650 KB）+ 背景图
└─ .gitignore            忽略 picture/ 与预览图
```

- 12 张头像由 `picture/` 的原图**中心正方形裁切并缩放到 512×512**，把总素材从 **12.4 MB 压到 646 KB**，手机加载更快。
- 圆徽章绘制时还会再做一次“人脸偏上”的二次裁剪（`faceWindow()`），竖图/横图都不会被拉伸变形。

## 本地运行

无需安装、无需构建，直接用浏览器打开 `index.html` 即可；也可用任意静态服务器托管。

```bash
# 例如
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术说明

- 纯静态网页：单个 `index.html`（HTML + CSS + 原生 JavaScript），无后端、无第三方运行时依赖。
- 自研 2D 圆形物理：重力、墙体与圆形碰撞冲量、摩擦、同级合成判定；每帧按约 120Hz 拆子步（最多 4 步）。
- **等级链只在一处定义**：`LEVELS` 数组（下标 = 等级）：`radius` 从小到大递增，`asset` 指向 `assets/level_N.jpg`；其它逻辑（最大等级、投放池、难度、图鉴、分数、结束文案、庆祝标题）全部从该数组推导。
- **半径**严格按 **×1.2** 递增：26 / 31 / 37 / 45 / 54 / 65 / 78 / 93 / 112 / 134 / 161 / 193。
- 存档都在浏览器 `localStorage`（键前缀 `merge-yanglukai:`）：`best:v2` 分难度最高分、`codex:v1` 图鉴解锁、`synth:v1` 历史最高合成；清空只要在控制台 `localStorage.clear()` 后刷新。
- 已适配移动端（viewport、触控、陀螺仪、添加到主屏幕）与桌面端键盘操作。
